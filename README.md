# Photocatalyst GA

光触媒探索用のブラウザアプリ。GA_for_photocatalyst.ipynbとfitness_GA.ipynbの規則を基に作成。

## 起動

index.htmlをブラウザで開く。インストール不要。デモを読み込んで「次世代を生成」で確認できる。

## 入力と運用

CSVの必須列：Sample, Co, Ni, Cu, Pd, Ag, Ir, Pt, Au, Score。
各金属の値は遺伝子番号（整数）で、wt%ではない。各候補の遺伝子合計は15以下。8元素には共通の最大値を適用する。旧CSVはRu・Rhがともに0の試料を読み込む。
Scoreは大きいほど良い実験評価値。Fitnessを使うモードではFitness列も必須。
各遺伝子の標準範囲は0〜15、合計上限15。合計15未満も採用し、残りを埋めない。
次世代の初期設定はランダム4、交叉6、突然変異4、エリート0の14組成。
今回のG0はdata/G0_seed20261118.csv。Au入り10本・Auなし4本で、全組成に4元素以上を含める。
G0の最低4元素・Au比率は初代のみの設計で、次世代には固定しない。
G0生成機能はページに追加しない。generate-g0.jsは今回の配合を再現するオフライン補助スクリプト。
シード20261118。各元素0〜15・合計15以下で、合計と配分をランダム化する。Scoreは空欄のまま。
交叉は各元素について片方の親の番号を継承。変異は1または2元素。
新規候補は入力世代と今回生成した候補との重複を避ける。全過去世代との重複判定は未実装。
エリートは再測定せず引き継ぐ規則で元の名前とScoreを保持。
同点のScore、または全て0のFitnessは均等選択。
乱数シードで同じ入力・設定なら再現可能。NumPyとは乱数生成器が異なるためPython版と候補は一致しない。
生成不能時はエラーで停止し、不足した候補を黙って出力しない。
結果CSVをダウンロードし新規候補のScoreを測定後に入力、そのCSVを次回読み込む。
作業ファイルJSONで設定・入力・出力・読込世代の平均と最高値を保存できる。
世代別表示は読込履歴の数値一覧。折れ線グラフ・濃度設定は未実装。分注コマンドCSVは保存後にWindows側のcommandsフォルダへ配置する。
データはサーバーに送信しない。自動保存はないので作業ファイルを保存する。
